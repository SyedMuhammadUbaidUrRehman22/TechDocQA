# Dataset preparation

The manifest is explicitly a draft, not a selected or frozen corpus. No files, licenses, hashes, benchmark labels or review evidence have been fabricated. Corpus selection remains an open Phase 1 gate.

Before freezing it, select 15–30 public/openly licensed documents across 3–5 technologies, <=50 MB, including at least 3 Markdown, 3 HTML, 3 text PDFs and 1 TXT. Each document record must include source_key, relative local path, technology, format, source URL, license/terms, raw_hash (SHA-256 bytes) and content_hash (SHA-256 normalized text, computed after normalization exists). The approximate chunk target is <=3000. Keep the downloaded files under ignored data/corpus unless redistribution is explicitly permitted.

DS-05 synthetic fixtures are created with ingestion/parser tests in Phase 2–3; they must not enter the corpus. Smoke questions are authored only after corpus selection: 20 answerable + 10 unanswerable, stable source/section/text anchors, reviewed by a second person with disagreements recorded. Full benchmark retains smoke and has <=50 questions. Benchmark files and results are not created as empty placeholders.

Phase 3A's approved source catalog is `[[online.sources]]` in `config/default.toml`, not a second dataset list. Kafka/Airflow are enabled; PostgreSQL/Spark/Redis/Docker require activation. Add an explicit HTTPS entry, host/path scopes and finite pages to approve a source; a URL alone does not authorize all pages on its host. Keep licensing/usage status unverified until reviewed.

The committed manifest now points to the runtime online candidate projection at `data/online/corpus_manifest.json`. Ingestion generates it from SQLite versions/attempts, with actual IDs, titles/technology, canonical/final URLs, UTC retrieval times, HTML format, raw/extracted hashes, extraction outcome, policy status and relative paths. It is reproducible from the registry via `techdocqa.ingestion.online.export_manifest`; it is not an independent registry. Paths are relative to the configured data directory. Raw snapshots and extracted text stay in ignored runtime data; do not commit downloaded bodies without a separate documented redistribution decision.

These are unfrozen candidates. URLs do not count as local documents; saved HTML pages may be reviewed as actual HTML candidates but cannot satisfy Markdown/PDF/TXT counts. Two live smoke pages under ignored test scratch are not selected reference-corpus files. No normalized content hashes, course corpus freeze or dataset acceptance is claimed. See [Phase 3A evidence](../docs/PHASE_3A_STATUS.md).
